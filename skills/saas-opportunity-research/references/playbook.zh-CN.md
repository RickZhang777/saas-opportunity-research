# Web 出海与 SaaS 选品工作手册

[English](playbook.en.md) · **简体中文**

<a id="screen"></a>
## 1. 判断哪些产品值得花时间

先记录目标人群和国家、创业者能投入的时间与资源、产品范围、本轮交付终点。年龄、流量规模和推荐数量由用户选择。做早期跟随时，可以从这类产品开始找：浏览器可用、资源相近的经营者、买家任务具体、近期上线、同口径两个月已有正增量。有第三个月数据就补。年龄和排除条件会改变决策时，按用户标准执行。

同时按买家、任务和交付物检索。例如，把「记账员核对银行流水 CSV」与新收录、细分类榜和公开收款资料一起查。[Toolify](https://www.toolify.ai/)、[Traffic.cv](https://traffic.cv/)、[There's An AI For That](https://theresanaiforthat.com/) 和 [TrustMRR](https://trustmrr.com/) 都可作为发现入口。优先查可合法读取的官网、带日期的买家自述及目录背后的原始证据。来源读不到时，记录实际尝试，再继续能独立完成的工作。

按稳定产品 ID、官网域名和已核别名去重。区分重定向、品牌迁移和产品首发。目录新收录只代表一次发现。用带日期的创始人或团队资料判断经营资源，一个创始人字段、收费记录或朴素页面都不足以证明是单人运营。

使用榜单时，记录来源、类别、统计期、排序指标、可见范围及榜长。分页末尾可能还在全榜中部。绝对增量榜的名次描述变化，访问总量另看。同口径才比较榜位，首次入榜单列。成熟头部产品可用于比较用户现有选择。

<a id="evidence"></a>
## 2. 为值得深查的产品补证

有足够样本时，比较 3–5 个直接同行或相近替代。免费工具或人工流程也可能是最强对手。关键判断附原链接、采集日期、统计期、覆盖范围、指标及局限。

| 维度 | 要核的内容 |
|---|---|
| 产品和买家 | 使用者和付款者、购买触发点、复用单位、输入 → 处理 → 输出。分清官网宣称、演示和自己实际使用的结果。查客户已为这件事花的钱、时间或返工。 |
| 增长 | 优先取最近 2–3 个完整月。同域名、来源、指标、设备和地区口径才比较。记录基数、增量及增幅，分清缺失、零、过期、受阻和冲突。零基数无可定义的增幅。至少两个期间的增速才可比较加速。注明估算与小样本。 |
| 流量质量 | 可读时查国家、渠道和付费任务关联的落地页。品牌导航、免费工具和投放都可能抬高流量。共用上游的两个供应商只能有限交叉核验。 |
| 年龄与经营者 | 分开域名注册、最早有日期的产品记录、公司成立、收录和实际首发。团队自述、外包、人力支持和分发资产分别记录。 |
| 定价与收款 | 核官网币种、付款周期、年付总额、免费额度、用量和额外费用。分开推荐标签、默认选项和真实销量。官网支付披露、平台核验接口与实际结账现场分开。到达授权边界即停。 |
| 买家行为 | 找带日期的最近一次操作、既有付费、实际采用、复用与投诉。标说话者和样本局限。平台收入是一份有口径的快照。净利润、退款、留存、MRR 和实收分开。 |
| 竞争 | 对齐同一个买家、触发时刻和可验收结果。低价竞品、现成平台内功能、手工表格都可能比头部产品更贴近真实选择。 |
| 交付和经济账 | 只承诺一项可验收的交付。查上游依赖、输出商用和素材再分发权限、重试、人工验收、售后和失败恢复。获客前单笔贡献以实收减可变处理、重试、存储、支付费、退款准备和必要人工。无可靠值时留未知或写清假设。 |

不用口径或时间窗不匹配的流量和付款估算转化率。两个观测点只能判断一个区间涨跌。要称加速，至少比较两个口径一致的区间增长率。

给决策证据同时标**对象**（竞品、现有替代、自己方案）和**等级**（猜想、桌面信号、真实行为、交易）。同行的收款放在同行交易栏。买家采用我们的结果属于自己的行为证据。保留卖家自述、独立评价、估算和自己观察之间的区别。

<a id="decision"></a>
## 3. 从证据走到决定

用一句话写出**谁付款、何时遇到问题、什么结果可以验收**。说明现在如何解决、我们能量化改善哪一步、去哪找到正在做这件事的买家。同行已有同类功能时，用同一输入比较完整任务，实测拟改善的那一步。换品牌、换语言、换套餐、便宜，都需要有买家实际选择理由。

- **优先验证**适用于买家具体可触达、已有可信成本或付款线索、能低成本验收。写清影响决策的缺口。
- **观察**适用于痛点看起来合理，但付款、获客、适配或交付仍不明。
- **暂缓**适用于免费替代过强、关键资产不可复制、交付太重或不符合用户范围。

写最强反证。根据竞品推导时，说清什么资源可能无法复用。最多先做一个实验，列唯一最大未知、买家筛选与渠道、单点交付、报价或行动请求、工时和现金上限、通过／继续／停止条件。小样本用来决定下一步投入。招募失败单列为触达未验证，与看过实物报价后拒绝区分。需要大量人工代改时，把这部分工时算入贡献。

获授权后，用合格的真实样本与买家原方法比较。实际采用和付款分开记录，称赞只作反馈。得到足够行为证据后，再按用户决定写单点范围和验收。

<a id="review"></a>
## 4. 交付报告和维护候选库

报告做到能支持决策即可。可用表头为**网站｜买家｜任务和结果｜报价｜增长｜收款证据｜年龄与团队｜替代｜建议**，附录保存详情和来源。研究站数和合格机会数分别统计。

维护库时，按稳定 ID 保留一份产品记录，按买家、触发点、结果另建需求方向。保留旧证据、日期与状态变更。用户决定和助手建议分字段。结尾写计划范围、实际完成、已试路径、缺项或受阻点、对判断的影响和下一步。按实际区分尚未执行和外部阻碍。文件存在和结构校验只说明交付一致性。

每周同时比较方向和网站，说明什么改变了优先级、保留哪些旧决定，最多给一个首选实验和一个有意义的备选。立项交接包含证据索引、未知、反证、购买原因、范围、验收与授权状态。

<a id="example"></a>
## 示例（以下数据均为虚构）

两个网站都能把采访录音转成文字。我们想验证的是：小型口述史机构的编辑会不会为**每份采访的可追溯引语表**付费。

| 信号 | 如何解读 |
|---|---|
| A 站同源月访问估算 420 → 950 → 1,280 | 连涨两次，增量 +530、+330，最新绝对增量和增速均下降。属于竞品桌面信号。 |
| B 站 0 → 90 → 260，收费页列 $12／月 | 零基数的增幅无法计算，0 也可能是覆盖不足。非零基数可确认一次增长。价格是公开报价。 |
| A 站平台核验近 30 天收入 $230，买家构成和利润未知 | 属于竞品交易证据。和月访问统计期、口径不同。自己方案没有交易证据。 |
| 一名编辑说先用免费转写，再手工核姓名和时间码 | 如果能追溯到具体日期与最近任务，支持现有工作流有返工。可看材料或操作，测量实际耗时。 |

**观察。** 最强反证是免费转写加人工核对已经够用。实验提案是在用户授权后，从公开口述史社群找到 5 位近期有合格录音的编辑，用获准样本制作带原时间码的引语表，试报 $15 一次。假设两天、额外现金不超过 $30，另计人工。至少两位独立买家付款并使用结果，且审核工时在约定范围内，才继续投入。触达不到合格对象，先记渠道未验证。看过成品和报价仍拒绝，按实际原因调整或停止。这些数字是实验决策线。
